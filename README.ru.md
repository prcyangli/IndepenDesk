# IndepenDesk

[English](README.md) | [Türkçe](README.tr.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Italiano](README.it.md) | **Русский** | [中文](README.zh-CN.md) | [日本語](README.ja.md)

**Независимые виртуальные рабочие столы для каждого монитора в Windows** — аналог функции macOS «Мониторы используют разные пространства Spaces».

## Проблема

Виртуальные рабочие столы Windows глобальны: `Win+Ctrl+←/→` переключает **все мониторы сразу**. В macOS у каждого экрана свои Spaces, и переключается только экран под курсором. IndepenDesk переносит это поведение в Windows.

## Возможности

- 🖥 **Рабочие столы для каждого монитора** — переключение затрагивает только монитор под мышью; остальные не меняются.
- ➕ **Динамическое и независимое число столов** — каждый монитор начинает с одного стола; свайп вправо в конце создаёт новый (до 9 на монитор). Пустые столы в конце удаляются автоматически.
- 🔢 **Глобальная нумерация** — номера продолжаются между мониторами (Монитор 1: 1-2-3, Монитор 2: 4-5-6). `Ctrl+Alt+цифра` переходит к нужному столу.
- 🎞 **Анимация в стиле macOS**, ограниченная монитором.
- 🗂 **Обзор** (`Ctrl+Alt+↑`) — сетка в духе Mission Control с перетаскиванием: перемещайте окна между столами и мониторами, переносите целые столы на другой монитор, контекстное меню перемещения.
- 🌍 **8 языков** — определяются автоматически, меняются в меню в трее.
- 🔄 **Проверка обновлений** через GitHub Releases.
- 🛟 **Защита от сбоев** — скрытые окна журналируются на диск и восстанавливаются при следующем запуске.

## Установка

1. При необходимости установите [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0).
2. Скачайте `IndepenDesk-vX.Y.Z-win-x64.zip` со страницы [Releases](https://github.com/harungecit/IndepenDesk/releases), распакуйте и запустите `IndepenDesk.exe`.
3. Приложение живёт в системном трее. Автозапуск: `Win+R` → `shell:startup` → поместите туда ярлык.

## Сочетания клавиш

| Сочетание | Действие |
|---|---|
| `Ctrl+Alt+←` / `Ctrl+Alt+→` | Предыдущий / следующий стол на мониторе под мышью (в конце `→` создаёт новый) |
| `Ctrl+Alt+↑` | Открыть/закрыть обзор |
| `Ctrl+Alt+1..9` | Перейти к столу с этим глобальным номером |
| `Ctrl+Alt+Shift+←/→` | Переместить активное окно на соседний стол |

При каждом переключении появляется индикатор («Рабочий стол 4 — Монитор 2 • 2/3»). В меню трея есть пункт **Как пользоваться…** с анимированным руководством по жестам.

## Сенсорная панель (свайпы как в macOS)

По умолчанию свайп четырьмя пальцами запускает **глобальное** переключение Windows. Чтобы заменить его:

1. Откройте **Параметры → Bluetooth и устройства → Сенсорная панель → Дополнительные жесты**.
2. Для свайпов четырьмя пальцами выберите **Настраиваемое сочетание клавиш** и запишите:
   - влево → `Ctrl+Alt+←`, вправо → `Ctrl+Alt+→`, вверх → `Ctrl+Alt+↑`
3. Настраиваемое сочетание автоматически заменяет стандартное поведение — переключается только монитор под курсором.

## Как это работает

IndepenDesk не использует глобальную систему Windows. Он ведёт наборы окон для каждого монитора и при переключении скрывает/показывает только окна этого монитора (`ShowWindow`). Скрытые окна исчезают также из панели задач и Alt-Tab. Новые окна привязываются к активному столу своего монитора.

## Известные ограничения

- Окна приложений с правами администратора нельзя скрыть, если IndepenDesk сам не запущен от администратора.
- Родное `Win+Ctrl+←/→` по-прежнему выполняет глобальное переключение — просто не используйте его.
- `Ctrl+Alt+←/→` может конфликтовать с горячими клавишами Intel «поворот экрана»; при необходимости отключите их.
- Контекстное меню панели задач Windows 11 нельзя расширить; используйте меню обзора.

## Сборка

```
dotnet publish -c Release -r win-x64 --self-contained false /p:PublishSingleFile=true -o publish
```

Требуется .NET 8 SDK. Релизы автоматически собираются GitHub Actions при пуше тега `v*`.
