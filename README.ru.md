# IndepenDesk

[English](README.md) | [Türkçe](README.tr.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Italiano](README.it.md) | **Русский** | [中文](README.zh-CN.md) | [日本語](README.ja.md)

**Независимые виртуальные рабочие столы для каждого монитора в Windows** — аналог функции macOS «Мониторы используют разные пространства Spaces».

## Проблема

Виртуальные рабочие столы Windows глобальны: `Win+Ctrl+←/→` переключает **все мониторы сразу**. В macOS у каждого экрана свои Spaces, и переключается только экран под курсором. IndepenDesk переносит это поведение в Windows.

## Возможности

- 🖥 **Рабочие столы для каждого монитора** — переключение затрагивает только монитор под мышью; остальные не меняются.
- ➕ **Динамическое и независимое число столов** — каждый монитор начинает с одного стола; переход вправо в конце создаёт новый (до 9 на монитор). Неиспользованные столы, созданные таким способом, удаляются после ухода с них; пустые столы из Обзора сохраняются до ручного закрытия.
- 🔢 **Глобальные цифровые сочетания** — `Ctrl+Alt+цифра` переходит между мониторами в порядке экранов; Обзор и OSD используют локальную нумерацию каждого монитора.
- 🔔 **Компактный экранный индикатор** после каждого переключения, без анимации, способной перехватить фокус.
- 🗂 **Обзор** (`Ctrl+Alt+↑`) — сетка в духе Mission Control с перетаскиванием: перемещайте окна между столами и мониторами, переносите целые столы на другой монитор, контекстное меню перемещения.
- 📌 **Общая панель задач** (опционально, меню в трее) — окна всех рабочих столов остаются в панели задач и Alt-Tab; щелчок по окну сразу переключает на его рабочий стол.
- 🌍 **8 языков** — определяются автоматически, меняются в меню в трее.
- 🔄 **Проверка обновлений** через GitHub Releases.
- 🚀 **Запускается вместе с Windows** по умолчанию — можно отключить в любой момент из меню в трее.
- 🛟 **Защита от сбоев** — скрытые окна журналируются на диск и восстанавливаются при следующем запуске.

## Установка

Работает в Windows 10 (1607+) и Windows 11 на **x64, x86 и ARM64**. Все пакеты автономны — среда .NET не требуется.

Пакеты этого форка ещё не опубликованы в менеджерах пакетов. До публикации используйте только Releases `prcyangli` ниже; прежний upstream-пакет winget устанавливает другой код.

**Установщик (рекомендуется):** скачайте `IndepenDesk-Setup-<версия>-<арх>.exe` со страницы [Releases](https://github.com/prcyangli/IndepenDesk/releases) и запустите — с необязательным ярлыком на рабочем столе, 7 языков установки.

**MSI** (корпоративное развёртывание / GPO): `IndepenDesk-<версия>-<арх>.msi`.

**Портативная версия:** `IndepenDesk-v<версия>-win-<арх>.zip` — распакуйте и запустите, установка не нужна.


Приложение живёт в системном трее (значок с двумя синими экранами).

## Сочетания клавиш

| Сочетание | Действие |
|---|---|
| `Ctrl+Alt+←` / `Ctrl+Alt+→` | Предыдущий / следующий стол на мониторе под мышью (в конце `→` создаёт новый) |
| `Ctrl+Alt+↑` | Открыть/закрыть обзор |
| `Ctrl+Alt+1..9` | Перейти к столу с этим глобальным номером |
| `Ctrl+Alt+Shift+←/→` | Переместить активное окно на соседний стол |

При каждом переключении появляется индикатор (например, «Рабочий стол 2»). В меню трея есть пункт **Как пользоваться…** с анимированным руководством по жестам.

## Сенсорная панель (свайпы как в macOS)

По умолчанию свайп четырьмя пальцами запускает **глобальное** переключение Windows. Чтобы заменить его:

1. Откройте **Параметры → Bluetooth и устройства → Сенсорная панель → Дополнительные жесты**.
2. Для свайпов четырьмя пальцами выберите **Настраиваемое сочетание клавиш** и запишите:
   - влево → `Ctrl+Alt+←`, вправо → `Ctrl+Alt+→`, вверх → `Ctrl+Alt+↑`
3. Настраиваемое сочетание автоматически заменяет стандартное поведение — переключается только монитор под курсором.

## Как это работает

IndepenDesk не использует глобальную систему Windows. Он ведёт наборы окон для каждого монитора и при переключении скрывает/показывает только окна этого монитора (`ShowWindow`). Скрытые окна исчезают также из панели задач и Alt-Tab. Новые окна привязываются к активному столу своего монитора.

Опциональный режим **общей панели задач** (меню в трее) вместо скрытия паркует окна неактивных столов за пределами экрана. Окна всех столов остаются в панели задач и Alt-Tab, а активация окна переключает на его стол. Запаркованные позиции журналируются так же, как скрытые, и восстанавливаются при следующем запуске после сбоя.

## Известные ограничения

- Окна приложений с правами администратора нельзя скрыть, если IndepenDesk сам не запущен от администратора.
- В режиме общей панели задач запаркованные окна продолжают отрисовываться (расход GPU/CPU немного выше, чем при скрытии). Если процесс принудительно завершён в этом режиме, запустите IndepenDesk 0.4.4+ снова, чтобы вернуть запаркованные окна на экран (старые версии не читают формат журнала v3).
- Родное `Win+Ctrl+←/→` по-прежнему выполняет глобальное переключение — просто не используйте его.
- `Ctrl+Alt+←/→` может конфликтовать с горячими клавишами Intel «поворот экрана»; при необходимости отключите их.
- Контекстное меню панели задач Windows 11 нельзя расширить; используйте меню обзора.
