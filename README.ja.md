# IndepenDesk

[English](README.md) | [Türkçe](README.tr.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Italiano](README.it.md) | [Русский](README.ru.md) | [中文](README.zh-CN.md) | **日本語**

**Windows でモニターごとに独立した仮想デスクトップ** — macOS の「ディスプレイごとに個別の操作スペース」の Windows 版です。

## 問題

Windows の仮想デスクトップはグローバルです。`Win+Ctrl+←/→` を押すと**すべてのモニターが同時に**切り替わります。macOS では各ディスプレイが独自の Spaces を持ち、カーソルのあるディスプレイだけが切り替わります。IndepenDesk はその挙動を Windows にもたらします。

## 機能

- 🖥 **モニターごとのデスクトップ** — 切り替えはマウスのあるモニターだけに作用し、他のモニターはそのまま。
- ➕ **動的で独立したデスクトップ数** — 各モニターは 1 つから始まり、末尾で右へ移動すると新規作成されます（最大 9）。この方法で作られた未使用デスクトップは離れた後に整理され、オーバービューで追加した空デスクトップは手動で閉じるまで保持されます。
- 🔢 **グローバル数字ショートカット** — `Ctrl+Alt+数字` はモニターをまたいで移動します（内蔵ディスプレイを先頭に、次に外付け画面を画面順に）。オーバービューでは内蔵ディスプレイが常にモニター 1 として最下部に表示されます。
- 🔔 **コンパクトな画面表示**が切り替えごとに現れ、フォーカスを奪うスライドアニメーションは再生しません。
- 🗂 **オーバービュー** (`Ctrl+Alt+↑`) — Mission Control 風のグリッドでドラッグ＆ドロップ：ウィンドウをデスクトップ間・モニター間で移動、デスクトップごと別モニターへ移動、右クリック移動メニュー。
- 📌 **共有タスクバー**（オプション、トレイメニュー）— すべてのデスクトップのウィンドウがタスクバーと Alt-Tab に残り、クリックするだけでそのデスクトップへ移動します。
- 🌍 **8 言語対応** — 自動検出、トレイメニューから変更可能。
- 🔄 GitHub Releases 経由の**更新チェック**。
- 🚀 **既定で Windows と同時に起動** — トレイメニューからいつでも無効にできます。
- 🛟 **クラッシュ耐性** — 非表示にしたウィンドウはディスクに記録され、次回起動時に復元されます。

## インストール

Windows 10 (1607+) と Windows 11 の **x64、x86、ARM64** に対応。すべてのパッケージは自己完結型で、.NET ランタイムは不要です。

このフォークのパッケージマネージャー登録はまだ公開されていません。公開までは以下の `prcyangli` Releases のみを使用してください。以前の upstream winget パッケージは別のコードをインストールします。

**インストーラー（推奨）：** [Releases](https://github.com/prcyangli/IndepenDesk/releases) から `IndepenDesk-Setup-<バージョン>-<アーキテクチャ>.exe` をダウンロードして実行 — デスクトップアイコンをオプションで選択可能、7 言語対応。

**MSI**（企業 / GPO 展開向け）：`IndepenDesk-<バージョン>-<アーキテクチャ>.msi`。

**ポータブル版：** `IndepenDesk-v<バージョン>-win-<アーキテクチャ>.zip` — 展開して実行するだけ。


アプリはシステムトレイに常駐します（2 つの青い画面のアイコン）。

## ショートカット

| ショートカット | 動作 |
|---|---|
| `Ctrl+Alt+←` / `Ctrl+Alt+→` | マウスのあるモニターで前 / 次のデスクトップ（末尾で `→` は新規作成） |
| `Ctrl+Alt+↑` | オーバービューの表示/非表示 |
| `Ctrl+Alt+1..9` | そのグローバル番号のデスクトップへ移動 |
| `Ctrl+Alt+Shift+←/→` | アクティブウィンドウを隣のデスクトップへ移動 |

切り替えのたびにインジケーター（例：「デスクトップ 2」）が表示されます。トレイメニューの**使い方…**にはアニメーション付きジェスチャガイドがあります。

## タッチパッド（macOS 風スワイプ）

既定では 4 本指スワイプは Windows の**グローバル**切り替えを起動します。上書きするには：

1. **設定 → Bluetooth とデバイス → タッチパッド → 高度なジェスチャ** を開く。
2. 4 本指スワイプの各方向で**カスタムショートカット**を選んで記録：
   - 左 → `Ctrl+Alt+←`、右 → `Ctrl+Alt+→`、上 → `Ctrl+Alt+↑`
3. カスタムショートカットを記録すると Windows の既定動作は自動的に置き換えられ、カーソルのあるモニターだけが切り替わります。

## 仕組み

IndepenDesk は Windows のグローバル仮想デスクトップを使いません。モニターごとにウィンドウの集合を管理し、切り替え時にそのモニターのウィンドウだけを非表示/表示します（`ShowWindow`）。非表示のウィンドウはタスクバーと Alt-Tab からも消えるため、本物のデスクトップ切り替えのように感じられます。新しいウィンドウは表示されたモニターのアクティブなデスクトップに割り当てられます。

オプションの**共有タスクバー**モード（トレイメニュー）では、非アクティブなデスクトップのウィンドウを非表示にせず、その場で最小化して退避します。すべてのデスクトップのウィンドウがタスクバーと Alt-Tab に残り、いずれかをアクティブにするとそのデスクトップへ切り替わります。退避位置も非表示と同様にディスクへ記録され、クラッシュ後の次回起動時に復元されます。

## 既知の制限

- 管理者権限で動くアプリのウィンドウは、IndepenDesk 自身を管理者で実行しない限り非表示にできません。
- タッチパッドの「カスタムショートカット」ジェスチャは合成キー入力です。管理者（昇格）ウィンドウにフォーカスがある間は Windows のセキュリティ（UIPI）によって破棄され、ジェスチャが効かなくなります。物理キーボードのショートカットとトレイメニューは引き続き使用できます。
- 共有タスクバーモードでは、退避したウィンドウはその場で最小化され（描画は停止します）。このモードでプロセスを強制終了した場合、ウィンドウは最小化されたまま残るため、タスクバーから手動で戻せます。IndepenDesk 0.4.4 以降を再起動すると自動で再管理されます（旧バージョンは v3 ジャーナル形式を読めません）。
- ネイティブの `Win+Ctrl+←/→` は引き続きグローバル切り替えを起動します — 使わなければ問題ありません。
- `Ctrl+Alt+←/→` は Intel グラフィックスの「画面回転」ホットキーと衝突する場合があります。必要なら Intel 設定で無効化してください。
- Windows 11 のタスクバーのコンテキストメニューはサードパーティから拡張できません。オーバービューの右クリックメニューをご利用ください。
